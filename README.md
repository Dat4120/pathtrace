# Pathtracing
A GLSL raytracing shader that utilizes light pathtracing techniques to render photorealistic objects using Physically Based Rendering (PBR) and Bidirectional Reflectance Distribution Function (BRDF) formulas. Runs on the web via WebGL2 for GPU-accelerated graphics. This program also includes a Bounding Volume Heirachy (BVH) allowing efficient ray/triangle raycasts for rendering triangle meshes.
